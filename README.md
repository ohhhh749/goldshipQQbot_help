# goldshipQQbot_help
本页面为基于astrbot和napcat黄金船聊天机器人的功能帮助页面，仅为群友提供功能查询
感谢 astrbot 与 napcat

实用功能
1.天气功能：
  使用自然语言llm会自动调起和风天气api，无需指令

2.戳一戳：
  双击头像戳一戳会随机发送一张meme图

3.设置精华(机器人需管理员权限）：
  引用要设精的内容，删掉@内容，输入“设精”
  例：【引用】
      设精

4.推特功能：
  发送分享链接自动解析内容
  管理员功能：/推特订阅 用户名 ：订阅用户，不需要输入 @。例如 /推特订阅 elonmusk
             /推特取消 用户名 ：取消该用户订阅
             /推特列表 ：查看本群订阅
             /推特帮助 ：查看帮助

2.明日方舟角色语音
这是一个用于获取和播放明日方舟所有角色语音的 AstrBot 插件。
  /mrfz [角色/皮肤] [语音] [语言]	：播放明日方舟语音、播放方舟语音	核心指令。角色支持模糊匹配；语音和语言均可省略。可直接输入皮肤名称，或使用 角色皮肤[皮肤名] 精确指定。
示例：/mrfz 超新星 问候 中文、/mrfz W皮肤[恍惚] 问候 中文
  /mrfz_list	 ：明日方舟语音列表	生成当前已下载语音的干员列表卡片，包含头像、已下载语言和自定义指令概览。
  /mrfz_fetch [角色]	 ：下载语音、获取语音	管理员指令。从 PRTS Wiki 下载指定干员的所有语音数据（含皮肤）。
  /mrfz_bind [触发词] [角色] [语音] [语言]	 ：绑定语音、语音绑定	管理员指令。将一句语音绑定到特定触发词。
  /mrfz_unbind [触发词]  	：解绑语音、语音解绑	管理员指令。解除指定的快捷触发词绑定。
  /mrfz_alias [别称] [干员]	 ：添加干员别称、干员别称	管理员指令。添加并保存自定义干员别称，例如 /mrfz_alias 水陈 假日威龙陈。
  /mrfz_alias_list	 ：干员别称列表	查看内置及自定义干员别称。
  /mrfz_help	 ：明日方舟语音帮助	生成可视化的帮助图片。

3.随机画廊
  /画廊目录  ： 画廊目录
  /创建文件夹 <文件夹名称>   ：创建文件夹  示范：创建文件夹 黄金船
  /添加图片 <文件夹名称> [附上图片]   ：添加图片，一条消息可以附带多张图片，最多 10 张。每张图片会以自动生成的唯一文件名保存；单张图片最大 20 MiB。
上传前必须先创建分类文件夹
  /来点<文件夹名称>    ：发送对应文件夹中的文件 示范：来点黄金船
